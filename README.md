## 📖 About The Project

Steam allows users to customize their profile descriptions and showcases, but the platform has very limited native text formatting options. Most existing online font generators are overloaded with intrusive ads, broken symbols, or heavy tracking scripts.

This project was built as a clean, minimalist alternative. It provides a straightforward interface where users can type their text, instantly preview how it looks, copy stylized variations in a single click, and paste them directly into Steam.

## ✨ Key Features

* **Zero Bloat & No Ads:** A clean, distraction-free interface focused purely on functionality.
* **Instant Conversion:** Text transforms into multiple Unicode font styles in real-time as you type.
* **One-Click Copy:** Quick copy-to-clipboard buttons with visual feedback.
* **Steam Friendly:** Uses fully compatible Unicode characters that render correctly within Steam's profile guidelines.
* **Fully Responsive:** Optimized for both desktop browsers and mobile devices.

## 🛠️ Built With

* **HTML5 / CSS3** — For a modern, adaptive, and minimalist UI layout.
* **Vanilla JavaScript (ES6+)** — For handling string manipulations, character mapping, and clipboard events without heavy framework overhead.
* **Render** — Hosted for fast, reliable, and continuous deployment.
