# 🎨 Steam Profile Font Generator

A free and simple web tool to create custom fonts and style text blocks for your Steam profile description, showcases, and nickname.

👉 **Try it out:** [https://steam-profile-gen.onrender.com/](https://steam-profile-gen.onrender.com/)

---

## 🚀 About the Project
This pet project was built to quickly transform Steam profile sections, showcases, or text blocks without dealing with clumsy, ad-heavy websites. Clean interface and instant results.

## ✨ Features
* Instant generation of custom fonts and stylish text symbols.
* One-click copy to clipboard.
* Fully responsive design for any screen size.
* Runs right in your browser with zero bloat.

## 🛠️ Tech Stack
Built with vanilla web technologies (HTML, CSS, JavaScript). Designed with a focus on speed and user experience.
